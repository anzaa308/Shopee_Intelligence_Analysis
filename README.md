# Shopee E-Commerce Market Intelligence & Pricing Analytics

## 📌 Project Overview
This project performs an end-to-end market intelligence analysis on Shopee transaction data to identify sales drivers, price elasticity, and category dynamics across product lines. The workflow combines **Python** for dataset cleaning and pre-processing, **SQL** for multi-level category aggregations, and an **Excel Dashboard** for executive visual analytics.

---

## 📁 Repository Structure
- `python/` : Contains the `.ipynb` Jupyter Notebook with data cleaning scripts, Pandas data transformations, and inline SQL queries.
- `SQL/` : Dedicated `.sql` query script containing aggregated category-level performance metrics.

---

## 📊 Key Insights & Analytical Findings
- **Price Elasticity & Volume Drivers:** High-volume lower-priced staple items drive the majority of order transactions, whereas premium categories yield higher overall margin value.
- **Category Clustering:** Evaluated unit sales against average price points to identify optimal pricing tiers for product promotion strategies.
